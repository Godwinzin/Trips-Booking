# Wandervia 

**Wandervia** is a modern, responsive web application designed to help users discover, filter, and book travel destinations worldwide. Built with clean vanilla JavaScript, HTML5, and CSS3, it offers an interactive map view, dynamic search filters, a saved destinations wishlist, and local storage integration.

---

## Key Features

* **Interactive Destination Search:** Browse a wide collection of worldwide travel destinations with real-time category and price filtering.
* **Interactive Leaflet Map:** View destination locations dynamically rendered on custom OpenStreetMap views.
* **Saved Wishlist:** Save favorite destinations locally so they remain available across browser sessions.
* **Responsive Mobile Navigation:** Features a mobile drawer menu, sticky header, and touch-friendly controls optimized for smartphones and tablets.
* **Automated Footer:** Includes a dynamic copyright year script and localized contact links (WhatsApp, Email, Social Channels).
* **Toast Notification System:** Instant visual feedback when users add items to their wishlist or update bookings.
